PERF-1

Free firmware that turns the M-VAVE FM-1 into a groovebox that plays by itself. By deamonSLINKY. Version 0.15.2.

Switch it on and music starts: drums, bass, a pad, an acid line and a plucked melody, in sixteen styles from techno to reggae. You steer it with the buttons and keys: change the chords, break it down and drop it back in, mute parts, throw on effects, or let the auto-DJ run the show. When you want more, nearly everything can be edited and saved. New here? Start with the beginner's guide.

InstallInstall it from this website in Chrome or Edge, with the FM-1 plugged in. You can go back to the original firmware the same way. Try it in your browserPlay with PERF-1 on screen, with sound, before you install anything. EditorChange any setting from your computer, and make your own DX7 sounds and hear them on the FM-1. Installing firmware is at your own risk. If something goes wrong, the installer can put the original firmware back, and an FM-1 that fails to start twice in a row starts in a safe mode the installer can reach. Section 1 of the manual explains it all.
